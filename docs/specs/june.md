# Required features
* Clear the contents of the sheet before writing to it
* Clear hidden rows and columns before writing
* Autofit column widths
* Append to the end of the current contents of a sheet, keeping what is there

* Set the NumberFormat property of a Range, in addition to Value2
* Read the NumberFormat, HasFormula, Formula properties of a Range
* Read the UsedRange property of a Sheet

* When adding a sheet, decide whether it should be first or last
* Delete a sheet
